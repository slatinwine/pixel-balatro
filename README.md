# 像素小丑牌 · PIXEL BALATRO

一款致敬 Balatro 的像素风纸牌肉鸽游戏：选牌组成德扑牌型，筹码 × 倍数结算分数，打过一关关盲注，用奖金在商店囤小丑牌，看你能撑过多少底注。

## ✨ 功能特性

- 完整牌型判定：高牌到同花顺、五条等，按计分张数结算「筹码 × 倍数」
- 三档盲注闯关：小盲 1× / 大盲 1.5× / BOSS 2× 目标分，可自选难度；BOSS 盲注会禁用一种花色的计分
- 商店系统：每个底注等级解锁的目标分递增（底注 1 为 300，逐级上涨），打完盲注进商店
- 多种小丑牌：如「每次出牌 +15 筹码」「打出同花倍数 ×2」「四条 / 同花顺倍数 ×3」，效果出牌时自动结算
- 商店「重掷」刷新货架（费用逐次递增），双击小丑牌可半价卖出
- 手牌排序（点数 / 花色）、帮助面板、WebAudio 芯片音效、CRT 扫描线像素美术

## 🚀 使用方法

用浏览器直接打开 `index.html`，点选手牌后「出牌」或「弃牌」，达到目标分数过关进入商店，无法达标则游戏结束。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript 单文件应用
- Web Audio API 合成 8-bit 音效，CRT 滤镜纯 CSS 实现
